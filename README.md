# 🇪🇸 Ava Learns Spanish

An interactive Spanish learning website designed specifically for Ava's Spanish studies at Browne Academy. This website features engaging flashcards with pronunciation, multiple-choice questions, and progress tracking.

## 🌟 Features

### Interactive Learning
- **41 Spanish Flashcards** covering essential vocabulary and phrases
- **Tap-to-Speak Pronunciation** using high-quality Spanish voices
- **Multiple Choice Questions** with immediate feedback
- **Progress Tracking** with scoring and statistics
- **Shuffle Mode** for varied practice sessions

### Categories Covered
- **Questions** - Essential "What" questions in Spanish
- **Greetings** - Common greetings and farewells
- **Polite Expressions** - Gratitude, apologies, and courtesy phrases

### Technical Features
- **Dark Mode Design** - Easy on the eyes for extended study sessions
- **Mobile Responsive** - Works perfectly on phones, tablets, and computers
- **High-Quality Voice Synthesis** - Automatically selects the best Spanish voice available
- **Sound Effects** - Audio feedback for correct/incorrect answers
- **No Installation Required** - Just open in any web browser

## 🎯 How to Use

1. **Open the Website** - Navigate to the live URL
2. **Tap Spanish Words** - Click on any Spanish word to hear pronunciation
3. **Select Answers** - Choose the correct English translation
4. **Get Feedback** - Immediate feedback with sound effects
5. **Track Progress** - Monitor your score and completion percentage
6. **Shuffle Cards** - Mix up the order for varied practice

## 📱 Browser Compatibility

- **Chrome/Edge** - Full support with Google voices
- **Safari** - Full support with Apple voices  
- **Firefox** - Full support with system voices
- **Mobile Browsers** - Optimized for touch interaction

## 🎤 Voice Features

The website automatically selects the highest quality Spanish voice available on your device:
- **Google Voices** (Chrome/Edge) - Neural and enhanced voices
- **Apple Voices** (Safari) - High-quality system voices
- **Microsoft Voices** (Edge) - Professional pronunciation
- **Fallback Support** - Works with any available Spanish voice

## 📚 Study Tips

1. **Practice Daily** - Even 10-15 minutes makes a difference
2. **Use Pronunciation** - Tap words to hear proper Spanish pronunciation
3. **Mix It Up** - Use shuffle mode to avoid memorizing order
4. **Track Progress** - Aim for higher scores with each session
5. **Repeat Difficult Cards** - Focus on areas that need more practice

## 🔧 Technical Details

- **Pure HTML/CSS/JavaScript** - No external dependencies
- **Web Speech API** - For Spanish pronunciation
- **Web Audio API** - For sound effects
- **Responsive Design** - CSS Grid and Flexbox
- **Progressive Enhancement** - Works even without advanced features

The website is hosted on GitHub Pages and automatically updates when changes are made to the repository.
